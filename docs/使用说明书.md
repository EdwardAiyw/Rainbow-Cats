## 1. 使用前准备

### 1.1 推荐环境

建议使用较新版本的以下浏览器：

- Microsoft Edge
- Google Chrome
- Android Chrome
- iPhone Safari

网页需要联网使用。若页面长时间没有响应，可先确认网络正常，然后刷新页面重试。

### 1.2 两位成员分别准备

每位成员都需要自己的：

- 用户名
- 密码
- 昵称
- 一次性恢复码

两位成员不要共用同一个账号。用户名用于登录，昵称显示在双人空间内，两者可以不同。

### 1.3 账号格式

- 用户名：`3–40` 位小写字母、数字或下划线。
- 密码：至少 `8` 位。
- 昵称：最多 `40` 个字符。

> [!IMPORTANT]
> 创建或加入空间后，系统会显示一次恢复码。恢复码只显示一次，请立即保存到安全位置，不要发送给其他人，也不要放入公开聊天、截图或代码仓库。

## 2. 创建或加入双人空间

每个空间最多只能有两位成员。通常由第一位成员创建空间，第二位成员使用邀请码加入。

### 2.1 第一位成员创建空间

1. 打开 <https://rainbow.251104.xyz>。
2. 在登录页选择“创建空间”。
3. 填写用户名、密码和昵称。
4. 点击“创建空间”。
5. 复制并妥善保存页面弹出的一次性恢复码。
6. 登录后，在页面右上角找到邀请码。
7. 通过可信方式把邀请码发给第二位成员。

邀请码通常以 `RC-` 开头。邀请码用于加入共同空间，不是登录密码。

### 2.2 第二位成员加入空间

1. 打开同一个网站。
2. 在登录页选择“加入空间”。
3. 填写自己的用户名、密码和昵称。
4. 输入第一位成员提供的邀请码。
5. 点击“加入空间”。
6. 复制并妥善保存页面弹出的一次性恢复码。

加入成功后，两位成员会看到同一个空间中的共享任务、礼物、菜谱、日程和账本数据。

### 2.3 提示“空间已满”

一个空间最多两位成员。出现此提示通常表示：

- 已经有两位成员加入；或
- 使用了另一个已满空间的邀请码。

请与空间创建者核对邀请码，不要反复创建新账号尝试加入。

## 3. 登录、退出与恢复账号

### 3.1 登录

1. 在登录页选择“登录”。
2. 输入用户名和密码。
3. 点击“登录”。

登录成功后，当前浏览器会保存会话。正常刷新页面通常不会退出登录。

### 3.2 退出登录

桌面端的“退出登录”位于左侧导航底部。点击后会结束当前浏览器中的登录状态，但不会删除账号和数据。

如果在公共设备上使用，结束后务必退出登录，并关闭浏览器窗口。

### 3.3 忘记密码

1. 在登录页选择“恢复账号”。
2. 输入用户名。
3. 输入创建账号时保存的恢复码。
4. 设置至少 8 位的新密码。
5. 点击“重置密码”。
6. 返回登录页，使用新密码登录。

重置密码后，旧会话会失效，需要重新登录。

### 3.4 恢复码丢失

当前版本没有通过手机、邮箱或客服找回恢复码的流程。恢复码丢失后，用户无法自行重置密码，因此建议：

- 将恢复码保存到可信密码管理器；
- 不要只保存在当前浏览器或当前手机里；
- 不要把恢复码和密码放在同一个公开位置。

## 4. 页面和导航说明

登录后，主要页面包括：

| 页面 | 主要用途 |
| --- | --- |
| 今天 | 查看积分、待完成心愿、近期日程和最近支出 |
| 心愿与任务 | 发布任务、查看任务、由另一位成员完成任务 |
| 礼物与收藏 | 上架礼物、兑换礼物、查看和使用个人收藏 |
| 菜谱 | 保存双方共享菜谱、搜索可选的官方或 AI 菜谱 |
| 日程 | 创建双方共享日程、连接可选 CalDAV 账号 |
| 账本 | 记录共同支出、查看本月支出和预算状态 |
| 相册 | 保存图片链接及说明 |
| AI 助手 | 对话、生成待确认操作提案 |
| 设置 | 修改昵称、绑定微信助手、退出或删除账号 |

页面右上角显示当前空间的邀请码。旁边的“↻”按钮用于重新加载当前页面数据。

## 5. 今天

“今天”是登录后的概览页，显示：

- 我的积分；
- 尚未完成的心愿；
- 接下来的日程；
- 最近的共同支出。

你可以直接在此页面点击“新增”创建任务，或点击“记一笔”记录支出。

如果另一位成员刚完成操作，而你的页面还没有变化，请点击右上角“↻”按钮或刷新浏览器。

## 6. 心愿与任务

### 6.1 新增任务

1. 进入“心愿与任务”。
2. 点击“新增任务”。
3. 填写标题。
4. 按需填写描述。
5. 设置 `1–500` 的积分。
6. 点击“保存”。

任务会出现在双方的任务列表中。

### 6.2 完成任务

任务只能由发布者之外的另一位成员完成：

1. 另一位成员进入“心愿与任务”。
2. 找到仍可完成的任务。
3. 点击“完成”。

完成后：

- 任务变为已完成；
- 任务不能再次完成；
- 任务发布者获得该任务对应的积分；
- 积分最高为 `500`。

### 6.3 为什么看不到“完成”按钮

以下情况不会显示“完成”按钮：

- 任务是你自己发布的；
- 任务已经完成；
- 页面数据尚未刷新。

## 7. 礼物与收藏

### 7.1 上架礼物

1. 进入“礼物与收藏”。
2. 在“礼物架”点击“上架礼物”。
3. 填写礼物名称。
4. 按需填写描述。
5. 设置兑换所需积分。
6. 点击“保存”。

### 7.2 兑换礼物

礼物只能由发布者之外的另一位成员兑换：

1. 找到仍可兑换的礼物。
2. 确认自己的积分足够。
3. 点击“兑换”。

兑换成功后：

- 从兑换者积分中扣除礼物积分；
- 礼物不能再次兑换；
- 礼物进入兑换者的“我的收藏”。

### 7.3 使用收藏

1. 在“我的收藏”找到未使用的礼物。
2. 点击“使用”。
3. 状态会变为“已使用”。

个人收藏只显示当前登录用户兑换到的礼物。

### 7.4 兑换失败的常见原因

- 积分不足；
- 正在兑换自己发布的礼物；
- 礼物已经被兑换；
- 另一台设备先完成了操作，当前页面尚未刷新。

## 8. 菜谱

### 8.1 添加自己的菜谱

1. 进入“菜谱”。
2. 在“我们的菜谱”点击“添加菜谱”。
3. 填写菜名。
4. 按需填写简介、食材和步骤。
5. 点击“保存”。

保存后的菜谱对空间中的两位成员可见。

### 8.2 搜索官方菜谱

“官方菜谱”由部署管理员配置的菜谱服务提供：

1. 在搜索框输入菜名或关键词，例如“红烧肉”。
2. 点击“搜索”。
3. 查看返回的菜谱简介、制作方法和可用的来源链接。

搜索结果仅供阅读，不会自动加入“我们的菜谱”。页面显示的每日限额是整个站点共享的服务限额，不是每个账号单独拥有的次数。

### 8.3 搜索结果标记

搜索结果可能显示：

- “官方菜谱”：来自已配置的菜谱服务；
- “相关官方菜谱”：与关键词相关的结果；
- “AI 生成参考”：官方服务无结果时由已启用的 AI 服务生成。

AI 生成内容仅供参考。涉及过敏原、特殊饮食或食品安全时，请自行核实食材和烹饪要求。

## 9. 日程与 CalDAV

### 9.1 新增共享日程

1. 进入“日程”。
2. 点击“新增日程”。
3. 填写标题、开始时间和结束时间。
4. 按需填写备注。
5. 点击“保存”。

保存后，两位成员都可以看到该日程。

### 9.2 连接 CalDAV

CalDAV 是可选功能，用于连接支持 CalDAV 的第三方日历服务。

1. 点击“连接 CalDAV”。
2. 填写 CalDAV 地址。
3. 填写第三方日历账号。
4. 填写应用专用密码。
5. 按需填写显示名称。
6. 点击“连接并保存”。

建议使用日历服务生成的应用专用密码，不要填写主账号密码。

> [!NOTE]
> 当前网页提供 CalDAV 连接入口，但没有单独的“立即同步”按钮。是否自动导入日程取决于部署端是否配置了同步流程。连接成功但暂时没有出现第三方日程时，请联系站点管理员。

## 10. 账本

### 10.1 记录支出

1. 进入“账本”。
2. 点击“记一笔”。
3. 填写金额。
4. 填写分类，例如“餐饮”“交通”或“日用品”。
5. 选择日期。
6. 按需填写备注。
7. 点击“保存”。

支出会显示在双方共享的账本中，金额统一显示为人民币符号和两位小数。

### 10.2 本月支出与预算

页面顶部显示：

- 本月支出合计；
- 月度预算；
- 支出占预算的进度。

> [!NOTE]
> 当前网页版本只能查看月度预算，没有提供设置或修改预算的按钮。如果页面显示“未设置”，需要由部署管理员通过服务端接口配置。

## 11. 相册

当前相册保存图片 URL 和文字说明，不会把手机或电脑中的图片文件直接上传到服务器。

### 11.1 添加照片记录

1. 先把图片保存到你信任且可以通过 HTTPS 访问的位置。
2. 复制图片的直接 URL。
3. 进入“相册”。
4. 点击“添加照片”。
5. 填写图片 URL。
6. 按需填写说明。
7. 点击“保存”。

### 11.2 注意事项

- 建议只使用 `https://` 图片地址；
- 链接失效后，网页将无法继续显示图片；
- 不要使用包含私密访问令牌、临时签名或敏感路径的公开链接；
- 添加记录不等于备份原始照片，请自行保留原图。

## 12. AI 助手

AI 助手是可选功能。只有站点管理员正确配置 OpenClaw 后，页面才会显示“OpenClaw 已连接”。

### 12.1 可以询问什么

可以尝试：

- “今天还有什么任务？”
- “最近记录了哪些共同支出？”
- “帮我整理一份周末安排。”
- “创建一个周末看电影的日程。”

### 12.2 写操作需要确认

AI 不会在一条对话后直接改动业务数据。涉及以下操作时，会先生成待确认提案：

- 创建任务；
- 上架礼物；
- 记录支出；
- 新增日程；
- 完成任务；
- 兑换礼物。

请在“待确认提案”中核对内容，确认无误后点击“确认执行”。点击确认后，系统才会执行写入。

### 12.3 使用建议

- 在确认前检查日期、金额、积分和标题；
- 不要向 AI 输入密码、恢复码或第三方服务密钥；
- AI 回答可能不完整或不准确，重要信息应自行核对；
- 对话记录目前主要保存在当前页面会话中，刷新页面后不应把它当作永久聊天档案。

## 13. 微信助手绑定

微信助手是可选功能，需要站点管理员部署并启用 OpenClaw 插件。

### 13.1 生成绑定码

1. 登录自己的 Rainbow-Cats 网页账号。
2. 进入“设置”。
3. 在“连接微信助手”中点击“生成绑定码”。
4. 复制弹出的 6 位绑定码。
5. 在 10 分钟内，把绑定码发送给指定的微信助手私聊。

新的绑定码会使当前账号之前尚未使用的绑定码失效。

### 13.2 两位成员分别绑定

- 每位成员必须登录自己的网页账号生成自己的绑定码；
- 不要替对方生成或发送绑定码；
- 当前部署约定中，本人使用 AI_1，对方使用小暖；以站点管理员实际提供的机器人账号为准。

绑定后，“我”和“我的”始终指当前发送微信消息的人，“我们”指两位成员共同的空间。

### 13.3 微信中的确认码

微信助手发起写操作时，会返回一次性确认码。确认码具有以下限制：

- 只能由发起操作的同一微信发送者使用；
- 只能在同一个机器人私聊中使用；
- 有有效期；
- 使用一次后失效；
- 连续多次输入错误会失效。

### 13.4 解除绑定

1. 进入网页“设置”。
2. 在已连接的微信助手旁点击“解除”。
3. 确认解除。

解除后，该微信身份将不能继续访问你的 Rainbow-Cats 数据，除非重新生成绑定码并绑定。

## 14. 设置与账号删除

### 14.1 修改昵称

1. 进入“设置”。
2. 在“当前昵称”中输入新昵称。
3. 点击“保存昵称”。

昵称会同步更新为当前账号在空间中的显示名称，用户名不会改变。

### 14.2 历史账号设置登录信息

从旧版迁移而来的账号可能尚未设置用户名和密码。此时设置页会显示“设置登录账号”：

1. 填写新用户名；
2. 设置至少 8 位密码；
3. 点击保存；
4. 立即保存只显示一次的恢复码。

### 14.3 永久删除账号

在“危险操作”中点击“永久删除我的账号”并确认后，操作不可恢复。

删除当前账号会移除：

- 当前用户资料和登录会话；
- 当前用户创建的任务和礼物；
- 当前用户拥有的收藏；
- 当前用户创建的菜谱和支出；
- 当前用户添加的照片记录；
- 当前用户创建的 AI 提案和微信绑定。

共享空间中由另一位成员创建的数据可能继续保留。若被删除用户原本是空间创建者且另一位成员仍在，空间所有者会转交给剩余成员；若空间只剩被删除用户，空间及其关联数据会被删除。

> [!CAUTION]
> 删除账号前请先确认不再需要相关数据。当前网页没有导出、回收站或撤销删除功能。

## 15. 手机端使用

手机端使用底部横向导航栏。入口较多时，可以左右滑动底部导航查看后面的页面。

使用建议：

- 表单内容较长时，在弹窗内部上下滚动；
- 输入法遮住按钮时，先收起键盘；
- 操作后等待成功提示再关闭页面；
- 两位成员同时操作后，如数据未更新，点击“↻”或刷新页面；
- 不建议在公共 Wi-Fi 或不可信设备上输入恢复码。

## 16. 数据与隐私

- 两位成员共享空间内的任务、礼物、菜谱、日程和账本数据。
- “我的收藏”只展示当前用户兑换的礼物。
- 浏览器通过服务端 API 访问数据，不直接连接数据库。
- 密码和恢复码不会以明文形式保存在数据库中。
- 第三方菜谱、CalDAV、OpenClaw 和微信助手属于可选外部服务；启用后，相关请求会按照部署配置发送到对应服务。
- 不要在任务、备注、菜谱、相册说明或 AI 对话中填写密码、恢复码、身份证号、银行卡号或第三方服务密钥。

## 17. 常见问题

### 17.1 页面打不开或一直加载

1. 检查网络连接。
2. 重新打开 <https://rainbow.251104.xyz>。
3. 尝试刷新页面或使用另一个现代浏览器。
4. 如果仍然无法访问，联系站点管理员检查服务状态。

### 17.2 登录后又回到登录页

可能是登录会话已过期、密码重置导致旧会话失效，或浏览器阻止了必要的站点数据。请重新登录，并确认浏览器未禁用该站点的 Cookie。

### 17.3 提示“账号已存在”

用户名已经被使用。请换一个用户名，或返回“登录”使用已有账号。

### 17.4 邀请码无效

- 确认没有多复制空格；
- 确认邀请码属于目标空间；
- 确认格式以 `RC-` 开头；
- 请创建者从页面右上角重新复制邀请码。

### 17.5 对方看不到我刚保存的内容

双方页面不会进行实时推送。请让对方点击右上角“↻”按钮或刷新浏览器。

### 17.6 无法完成任务或兑换礼物

检查是否正在操作自己发布的内容、内容是否已经被处理、积分是否足够，并刷新页面确认最新状态。

### 17.7 官方菜谱不能搜索

官方菜谱依赖站点管理员配置 TianAPI。未配置、达到每日限额或第三方服务异常时，搜索可能不可用，但自建菜谱仍可正常使用。

### 17.8 AI 助手显示“尚未启用”

这是 OpenClaw 未配置或当前不可用的提示，不影响其他功能。普通用户无法在网页中自行启用，请联系站点管理员。

### 17.9 CalDAV 连接失败

检查 CalDAV 地址、账号和应用专用密码是否正确。部分日历服务需要先在账号安全设置中生成应用专用密码。

### 17.10 图片无法显示

检查图片 URL 是否仍可访问、是否使用 HTTPS，以及图片服务是否允许其他网站加载该图片。临时链接过期后需要重新添加有效地址。

### 17.11 删除操作能否撤销

不能。任务完成、礼物兑换、收藏使用、AI 提案确认和账号删除都应在操作前核对。永久删除账号尤其无法撤销。
